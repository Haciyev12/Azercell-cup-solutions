# Azercell Cup 2025 — C++ Solutions

My solutions to problems from the **Azercell Cup 2025**, a national competitive programming contest in Azerbaijan. All solutions are written in C++ (C++17).

I also tutor students preparing for the Azercell Cup and the Republican Olympiad in Informatics.

## How to run

```bash
g++ -std=c++17 -O2 -o solution solution.cpp
./solution < input.txt
```

Each file reads from standard input and writes to standard output, like a typical online judge.
